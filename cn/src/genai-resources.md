# GenAI 学习资源

本页汇总了[机器学习基础](./ml-fundamental.md)和[机器学习系统设计](./MLSD/ml-system-design.md)中涉及的大语言模型（LLM）、多模态 AI、检索增强生成（RAG）、智能体 AI 和 GenAI 系统设计主题的补充学习资源。

## Educative.io

请选择能弥补你当前能力短板的资源，而不是把每门课程都学完。

### GenAI 与 LLM 基础

- [Generative AI Handbook](https://www.educative.io/courses/generative-ai-handbook) - 简要介绍 LLM、提示词工程、微调、向量数据库、RAG、扩散模型和智能体。
- [LLM Bootcamp](https://www.educative.io/courses/llm-bootcamp) - 更深入地讲解 transformers、嵌入向量、向量数据库、微调、LoRA/QLoRA、RAG、评估以及生产环境中的权衡。
- [Become an LLM Engineer](https://www.educative.io/path/become-an-llm-engineer) - 面向构建实用 LLM 应用的更全面技能路径。

### RAG 与生产系统

- [Build a RAG System with LangChain](https://www.educative.io/courses/rag-llm) - 讲解端到端 RAG 流水线，包括嵌入向量、向量存储、生成和优化。
- [Advanced RAG Techniques](https://www.educative.io/courses/advanced-rag-techniques) - 重点关注检索质量以及更高级的 RAG 配置。
- [LLMOps](https://www.educative.io/courses/llmops) - 涵盖生产级 LLM 系统中的评估、可观测性、反馈闭环、可靠性、缩放、延迟和成本。

### 智能体与智能体系统

- [Agentic AI Systems](https://www.educative.io/courses/agentic-ai-systems) - 介绍面向自主工作流的智能体架构和系统设计决策。
- [Agentic Design Patterns](https://www.educative.io/courses/agentic-design-patterns) - 讲解工具、检索、记忆、路由和评估器等智能体构建模块。
- [Build AI Agents and Multi-Agent Systems with CrewAI](https://www.educative.io/courses/build-ai-agents-and-multi-agent-systems-with-crewai) - 动手入门单智能体与多智能体工作流。

### 面试与系统设计准备

- [Grokking the Generative AI System Design](https://www.educative.io/courses/generative-ai-system-design) - 涵盖文本、图像、语音和视频生成的系统设计，包括训练、推理、缩放和评估。
- [Grokking the Machine Learning Interview](https://www.educative.io/courses/grokking-the-machine-learning-interview) - 回顾实用的机器学习概念和端到端面试案例。
- [Grokking the Machine Learning System Design Interview](https://www.educative.io/courses/grokking-the-machine-learning-system-design-interview) - 聚焦结构化的机器学习系统设计分析、生产环境权衡和模拟面试。

## 其他代码仓库

- [Production Level Deep Learning](https://github.com/alirezadir/Production-Level-Deep-Learning) - 生产级机器学习和深度学习系统设计资料。
