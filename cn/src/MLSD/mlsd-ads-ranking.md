# 广告点击预测

### 1. 问题定义
* 澄清性问题
  * 点击预测系统的首要业务目标是什么？
  * 我们要预测的是哪类广告的点击（例如展示广告、视频广告、赞助内容）？
  * 是否需要考虑特定用户分群或上下文（例如用户画像、浏览历史）？
  * 我们将如何定义并衡量点击预测的成功（例如点击率、转化率）？
  * 是否有负反馈特征（例如隐藏广告、拉黑等）？
  * 是否有疲劳期设定（即当用户无兴趣时，该广告在接下来 X 天内不再展示）？
  * 我们可以获取哪些用户-广告交互数据，能否将其用于训练模型？
  * 是否需要持续训练？
  * 我们如何收集负样本？（未点击、负反馈）

* 用例与业务目标
  * 用例：当有多个广告候选时，预测用户更可能点击哪一个广告。
  * 业务目标：通过向用户投放更相关的广告，提高点击率，并最大化广告库存价值，从而提升广告收入。
* 需求：
    * 具备实时预测能力，以支持动态广告投放。
    * 可扩展，能够处理大量广告曝光。
    * 与广告投放平台及数据源集成。
    * 持续进行模型训练与更新。
* 约束：
    * 隐私要求，以及对数据保护法规的合规性。
    * 实时广告投放的延迟要求。
    * 用户注意力有限，用户可能会很快决定是否点击广告。
* 数据：来源与可用性：
    * 数据来源包括用户交互日志、广告内容数据、用户画像以及上下文信息。
    * 用于模型训练和评估的历史点击与曝光数据。
    * 可用于监督学习的标注数据是否可用。
* 假设：
    * 用户点击行为会受到一些因素影响，而这些因素可以从历史数据中学习得到。
    * 广告内容及其相关性在点击预测中起重要作用。
    * 点击行为可以建模为一个分类问题。
  
* 机器学习问题建模：
    * 广告点击预测是一个排序问题

### 2. 指标
* 离线指标
  * CE
  * NCE（相对基线归一化）
* 在线指标
  * CTR（#clicks/#impressions）
  * 转化率（#conversion/#impression）
  * 收入提升（Revenue lift，随时间推移的收入增长）
  * 隐藏率（#hidden ads/#impression）

### 3. 架构组件
* 高层架构
* 我们可以使用 point-wise learning to rank（LTR）
    * 这是一个二分类任务，目标是预测用户是否会点击（1）某次广告曝光，或不点击（0）-> 给定一对<user, ad>作为输入 -> 输出点击或不点击
    * 特征可以包括用户画像、广告属性、上下文（例如设备、位置）以及历史行为。
    * 可用于预测的机器学习模型包括逻辑回归、决策树、梯度提升模型或深度神经网络。

### 5. 特征工程
* 特征选择
  * 广告：
    * ID
    * 类别
    * 图片/视频
    * 曝光次数 / 点击次数（ad、adv、campaign）
  * 用户：
    * ID、用户名
    * 用户画像（年龄、性别、位置）
    * 上下文（设备、一天中的时间等）
    * 交互历史（例如用户广告点击率、总点击次数等）
  * 用户-广告交互：
    * ID（user、ad）、交互类型、时间、位置、停留时长
* 特征表示 / 准备
  * 稀疏特征
    * ID：嵌入层（每种 ID 类型使用各自独立的嵌入层）
  * 稠密特征：
    * 互动特征：点击次数、曝光次数等
    * 直接使用
  * 图片 / 视频：
    * 预处理
    * 例如使用 SimCLR 转换为特征向量
  * 类别：文本数据
    * 归一化、分词、编码

### 6. 模型开发与离线评估
* 模型选择
  * LR
  * 特征交叉 + LR
    * 特征交叉：将 2 个或更多特征组合成新特征（例如求和、乘积）
      * 优点：能够捕获特征之间的非线性交互
      * 缺点：手工过程，且需要领域知识
  * GBDT
    * 优点：可解释
    * 缺点：不适合持续训练，无法训练嵌入层
  * GBDT + LR
    * GBDT 用于特征选择和/或提取，LR 用于分类
  * NN
    * 两种选择：单网络、双塔网络（user tower、ad tower）
    * 对广告点击预测的缺点：
      * 特征非常稀疏，而且数量巨大
      * 难以捕获成对交互（数量很多）
    * 在这里不是一个好的选择。
  * Deep and Cross Network（DCN）
    * 自动发现特征交互
    * 两个并行网络：deep network（学习复杂特征）和 cross network（学习交互）
    * 两种类型：stacked 和 parallel
  * Factorization Machine
    * 基于嵌入的模型，通过自动学习特征交互（即为特征学习嵌入）来改进 LR
    * w0  + \sum (w_i.x_i) + \sum\sum <v_i, v_j> x_i.x_j
    * 缺点：不像 NN 那样能从特征中学习高阶交互
  * Deep Factorization Machine（DFM）
    * 结合了 NN（用于复杂特征）和 FM（用于成对交互）
  * 先从 LR 开始建立基线，然后再实验 DCN 和 DeepFM
   
* 模型训练
  * 损失函数：
    * 二分类：CE
    * 数据集
      * 标签：正样本：广告展示后 < t 秒内用户点击广告；负样本：t 秒内未点击
  * 模型评估与超参数调优
  * 迭代
  
### 7. 预测服务
* 数据准备流水线
  * 静态特征（例如广告图片、类别）-> 批量特征计算（每日、每周）-> 特征存储
  * 动态特征：广告曝光次数、点击次数。
* 预测流水线
  * 两阶段（漏斗）架构
    * 候选生成
      * 使用广告主的定向条件（年龄、性别、位置等）
    * 排序
      * 特征 -> 模型 -> 点击概率 -> 排序
      * 重排序：业务逻辑（例如多样性）
* 持续学习流水线
  * 在新数据上微调、评估，如果指标提升则部署

### 10. 其他主题
* 校准：
  * 对预测概率进行微调，使其与实际点击概率对齐
* 数据泄露：
  * 来自测试集或评估集的信息影响了训练过程
  * 目标泄露、数据污染（从测试集泄露到训练集）
* 灾难性遗忘
  * 模型在新数据上训练后，失去了在先前已学习任务上的良好表现能力
