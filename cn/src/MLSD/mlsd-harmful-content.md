# 社交媒体中的有害内容检测

### 1. 问题定义
* 澄清问题
  * 我们要检测哪些类型的有害内容？（例如：仇恨言论、露骨图片、网络霸凌）
  * 有害内容可能来自哪些来源？（例如：社交媒体、UGC 平台）
  * 内容审核是否有特定的法律或伦理约束？
  * 预计每天需要分析的内容量是多少？
  * 支持哪些语言？
  * 是否有人工标注人员可用于打标？
  * 是否支持用户举报有害内容？（点击、文本等）
  * 这里是否需要可解释性？

* Integrity 涉及：
    * 有害内容（这里重点讨论）
    * 有害行为／有害行为主体
* 目标：监控帖子，检测有害内容，并进行降权／删除
* 有害内容类别示例：暴力、裸露、仇恨言论
* 机器学习目标：预测一条帖子是否有害
  * 输入：Post（多模态：文本、图片、视频）
  * 输出：`P(harmful)` 或 `P(violent)`、`P(nude)`、`P(hate)` 等
* 机器学习类别：多模态多标签分类
* 数据：5 亿帖子／天（其中约 1 万条有标注）
* 延迟：不同类别可以有不同要求
* 能向用户解释原因（类别）
* 支持不同语言？支持

### 2. 指标
- 离线
  - F1 score、PR-AUC、ROC-AUC
- 在线
  - prevalence（未被拦截的有害帖子占全部帖子的比例）、harmful impressions、有效申诉（被恢复）比例、主动发现率（系统检测数量 / 系统检测 + 用户举报检测数量）

### 3. 架构组件
* 多模态输入（文本、图片、视频等）：
  * 多模态融合技术
    * Early Fusion：先组合各模态，再做一次统一预测
    * Late Fusion：各模态独立处理，再融合预测结果
      * 缺点：需要按模态分别准备训练数据；单独看都安全的内容组合在一起后可能是有害的
* 多标签／多任务分类
  * 单个二分类器（`P(harmful)`）
    * 简单，但不可解释
  * 每个有害类别一个二分类器（`p(violence)`、`p(nude)`、`p(hate)`）
    * 模型多，需要分别训练和维护，成本高
  * 单个多标签分类器
    * 任务学习更复杂
  * 多任务分类器：同时学习多个任务
    * 共享层（学习任务间相似性）-> transformed features
    * 任务专属层：分类 head
    * 优点：单模型；共享层可避免冗余；某个任务的训练数据也可帮助其他任务（适合数据有限场景）

### 4. 数据采集与准备

* 当前可获得数据的主要参与方：
  * 用户
    * `user_id`、年龄、性别、位置、联系方式
  * 内容项（Posts）
    * `post_id`、`author_id`、文本内容、图片、视频、链接、时间戳
  * 用户-帖子交互
    * `user_id`、`post_id`、`interaction_type`、`value`、时间戳

### 5. 特征工程
特征：
帖子内容（文本、图片、视频）+ 帖子交互（文本 + 结构化特征）+ 作者信息 + 上下文

* 帖子
  * 文本：
    * 预处理（归一化 + 分词）
    * 编码（向量化）：
      * 统计方法（BoW、TF-IDF）
      * 基于机器学习的编码器（BERT）
    * 我们选择预训练的机器学习编码器（因为需要理解文本语义）
    * 我们选择 BERT 的多语言蒸馏版（更小、更快，且需要上下文），即 DistilmBERT
  * 图片／视频：
    * 预处理：解码、调整尺寸、缩放、归一化
    * 特征提取：预训练特征提取器
      * 图片：
        * CLIP 的视觉编码器
        * SImCLR
      * 视频：
        * VideoMoCo
* 帖子交互：
  * 点赞数、评论数、分享数、举报数（缩放）
  * 评论（文本）：与帖子文本处理方式类似（对评论的嵌入向量做聚合）
* 用户：
  * 只使用发帖作者的信息
    * 人口统计特征（年龄、性别、位置）
    * 账号特征（粉丝数／关注数、账号年龄）
    * 违规历史（违规次数、被举报次数、脏话占比）
* 上下文：
  * 一天中的时间、设备

### 6. 模型开发与离线评估
* 模型选择
  * 神经网络：我们使用 NN，因为它常用于多任务学习
* 超参数调优：
  * 隐藏层数、每层神经元数、激活函数、学习率等
  * 常用 grid search
* 数据集：
  * 自然标注（用户举报）——速度快
  * 人工标注（外包标注员）——准确
  * 我们使用自然标注作为训练集（速度），人工标注作为评估集（准确性）
* 损失函数：
  * `L = L1 + L2 + L3 ...`，对应每个任务
  * 每个任务都是二分类，因此每个任务可使用 CE
* 多模态训练的挑战：
  * 过拟合（某个模态如图片在训练中占主导）
    * gradient blending 和 focal loss

### 7. 预测服务
* 3 个主要组件：
  * 有害内容检测服务
  * 降权服务（有害概率高但置信度较低）
  * 违规处理服务（有害概率高且置信度高）
