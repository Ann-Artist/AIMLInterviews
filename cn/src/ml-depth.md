# <a name="depth"></a> 3. ML 深度

ML 深度面试通常旨在考察你在机器学习理论和实践两方面的理解深度，尤其是你声称自己实际做过的方向。虽然一开始听起来会有些吓人，但如果你对自己过去做过的工作足够熟悉，这反而可能是最容易的一轮之一。换句话说，ML 深度面试通常会围绕你之前做过的机器学习相关项目展开，而且会尽可能往深处问。

这类面试通常会从回顾你过去的某个项目开始（具体选哪个项目，取决于公司，有时由你来选，有时由面试官来选）。一开始一般是高层次讨论，随后面试官会逐步深入项目的一个或多个方面，有时甚至会一直追问到你答不上来为止（所以被问住是完全正常的，只是最好不要太早被问住！）。

准备这类面试最好的建议，就是把你以前做过的工作细节都搞清楚（而且要非常清楚），哪怕那已经是几年前的项目。
